仅保存元数据

任务 ID、角色、模型、状态、时间、字符数、token 用量、脱敏计数和固定错误分类。导出使用相同字段。

正文记录默认关闭

默认只保留元数据。单独开启正文记录后，新请求和回复先脱敏，再用 Windows 账户加密保存；输入与输出各最多 64,000 字符。历史请求不会补录。

发送前过滤

过滤平台保存的 API 密钥及常见凭据、邮箱、电话、URL 和本地路径。规则无法识别全部个人信息和业务机密，派发时仍需最小化上下文。

7 天保留期

最多保留 500 条任务记录，服务运行时定期清理。心跳超过 20 秒未更新的任务显示为连接中断，远端可能仍在处理。

手动恢复

重试会创建新请求，关联原记录且可能再次计费。服务重启只标记中断，不会自动重发；没有完整请求内容时无法恢复。

本机访问

服务只监听 127.0.0.1，拒绝跨站请求。当前 Windows 账户下的其他程序仍可能访问本地文件。
